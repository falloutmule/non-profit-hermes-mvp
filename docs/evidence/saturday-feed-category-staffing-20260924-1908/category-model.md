# Category model

Stable category definitions, effective-dated defaults and per-occurrence snapshots. Definition IDs and occurrence-category IDs are distinct. One active assignment per volunteer/occurrence. Per-category queues/reservations; derived aggregate capacity. Explicit staffing and category active flags, not inferred from zero capacity. Generic events preserved.

Pantry / PANTRY / 5; Harm Reduction / First Aid / Hygiene / SUPPLIES / 4; Meal / MEAL / 1. Standby enabled independently. DONE disabled on Saturday Feed.

Occurrence-only edits mark only changed category snapshots overridden; unchanged sibling categories keep inheriting defaults. Future changes preserve historical records and explicit overrides.
